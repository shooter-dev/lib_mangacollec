# USE CASE DOCUMENTATION

## GetAllAuthorsV2

**Description** : Récupère la liste complète des auteurs disponibles dans la base de données avec leurs 
informations essentielles et statistiques.

**Paramètres d'entrée** : Aucun

**Données retournées** :
- list
    - Author

**Cas d'usage métier** :
- Afficher un annuaire complet d'auteurs dans l'application
- Créer une liste de sélection pour filtrer par auteur
- Générer des statistiques sur les auteurs les plus prolifiques
