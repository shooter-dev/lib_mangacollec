## APITypeRepository

**Description** : Gère les opérations de récupération et de manipulation des données des types de séries dans l'API.

### Méthodes Disponibles
- `get_all_types_v1()` -> `GetAllTypesSerieV1Response`
    - **Endpoint** :
        - methode: `GET`
        - url: `/v1/types`
    - **Authentification** : false
    - **Type retourné** : GetAllTypesSerieV1Response
