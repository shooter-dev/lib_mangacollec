# REPOSITORY DOCUMENTATION

## APIJobRepository

**Description** : Gère les opérations de récupération et de manipulation des données des jobs dans l'api'.

### Méthodes Disponibles
- `get_all_jobs_v1()` -> `GetAllJobsV1Response`
    - **Endpoint** :
        - methode: `GET`
        - url: `/v1/jobs`
    - **Authentification** : false
    - **Type retourné** : GetAllJobsV1Response
