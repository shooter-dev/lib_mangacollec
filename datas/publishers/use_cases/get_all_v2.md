# USE CASE DOCUMENTATION

## GetAllPublishersV2

**Description** : Récupère la liste complète des éditeurs disponibles dans la base de données avec leurs informations
essentielles et statistiques.

**Paramètres d'entrée** : Aucun

**Données retournées** :
- list
    - Publisher

**Cas d'usage métier** :
- Afficher un annuaire complet d'éditeurs dans l'application
- Créer une liste de sélection pour filtrer par éditeur
- Générer des statistiques sur les éditeurs les plus prolifiques
- Identifier les éditeurs actifs ou fermés
