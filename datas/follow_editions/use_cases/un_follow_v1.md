# USE CASE DOCUMENTATION

## UnfollowEditionV1

**Description** : Supprime définitivement un suivi d'édition de la collection personnelle de l'utilisateur.

**Paramètres d'entrée** :
- `id_follow_edition` (str) : Identifiant unique du suivi à supprimer

**Données retournées** :
- Booléen : true si suppression réussie, false sinon

**Cas d'usage métier** :
- Nettoyer sa liste de suivis
- Supprimer définitivement le suivi d'une édition
- Gérer ses abonnements aux éditions
